Pronoms personnels et auxilliaires être et avoir

Utilisation des pronoms personnels

  • Liste des pronoms personnels:
    • Français Espagnol
    Je Yo
    Tu Tu
    Il/Elle/3ème forme (vouvoiement) El/Ella/Usted
    Nous Nosotros/Nosotras
    Vous Vosotros/Vosotras
    Ils/Elles/3ème forme (vouvoiement) Ellos/Ellas/Ustedes

  • 4 remarques importantes :

    • Les pronoms personnels ne sont pas obligatoires, la conjuguaison du verbe permet à elle seule de déterminer le pronom personnel. Ils peuvent cependant permettre de lever une ambiguité ou de marquer une forme d'insistance,
    • En amérique du sud, on utilise souvent ustedes à la place de vosotros,
    • Utilisation avec la préposition "con", pour le "je" et le "tu" on utilise "conmigo", "contigo" et avec le les autres personnes, le pronom personnel simple, ex: con el, ...,
    • Avec les prépositions segun, entre et hasta, on emploie le pronom personnel
      Selon toi : Segun tu, On le fera à nous deux : Lo haremos entre tu y yo, même moi je sais ça : Eso hasta yo lo sé.

Auxillaires être et avoir : Comment choisir ?

Utilisation de Ser et Estar


  • Auxillaire être / utilisation :
    • Auxillaire être Utilisation
    SER : Etat permanent origine/nationalité/profession/date & heure/traits de caractères / propriété / nature, ...
    ESTAR : Etat provisoire / passager situation géographique / position / état physique / fonction / résultat d'une action, ...
  • SER et ESTAR / utilisation :
    • Forme Conjuguaison
    SER soy, eres, es, somos, sois, son
    ESTAR estoy, estas, esta, estamos, estais, estan
  • HABER / utilisation :
    • Forme Conjuguaison
    HABER hé, has , ha, hemos, habeis, han
  • Remarques sur AVOIR :
    • Ne pas confondre l'auxilliaire avoir HABER et avoir dans le sens "posséder" TENER : tengo, tienes, tiene, tenemos, teneis, tienen.

Temps et conjuguaison

Les temps du présent

Présent de l'indicatif : presente de indicativo

  • Groupes de verbes :
    • Groupe Exemples de verbe Utilisation
    1er groupe : AR hablar/viajar/trabajar On retire le suffixe AR => o, as, a, amos, ais, an
    2ème groupe : ER comer/beber On retire le suffixe ER => o, es, e, emos, eis, en
    3ème groupe : IR venir/vivir/escribir On retire le suffixe IR => o, es, e, imos, is, en
  • Verbes irréguliers :
    • Diptongo : (e->ie, o->ue, u->ue) ex: jugar => juego
    Combio de vocal: (e->i ex: querer, preferir, dormir => quiero
    Irréguliers à la 1ère personne du singulier : estar (estoy), saber(sé), dar(doy), hacer(hago), tener(tengo), ... + verbes se terminant par acer, ocer, ecer, ucir ex: parecer => parezco, ...
    Les verbes pronominaux : constructions réfléchies
    ex: llamarse / levantares, ... (me/te/se/nos/os/se)
    Quand le COD/COI et le sujet se réfèrent à la même personne :
    => Claudia se présente dans ses tableaux : Claudia se pinta en sus cuadros
    => Claudia se maquille les lèvres : Claudia se pinta los labios

Présent progressif : action en cours / action en développement

  • Groupes de verbes :
    • être en train de estar + gerundio
    continuer à seguir + gerundio
  • Construction du GERUNDIO
    • Verbes du 1er groupe (AR) transformation en ANDO
    Verbes du 2ème groupe (ER), 3ème groupe (IR) transformation en IENDO
  • Remarques :

    • Attention !!! Pour certains verbes avec préposition => verbe + préposition + infinitivo

    continuer à volver a + infinitivo
    arrêter de dejar de + infinitivo
    commencer à acabar de + infinitivo
    terminer de terminar de + infinitivo

Présent du subjonctif

  • Utilisation :

    • Le subjonctif est le mode de la subordination et s'emploie pour exprimer une dépendance entre 2 actions/faits possibles qui expriment :

    • un désir Ojalà + subjonctif : Pourvu que,
    • un souhait desear que / querer que + subjonctif,
    • la défense no + subjonctif (No halgan huego : ne faîtes pas la grève),
    • une condition,
    • un doute j'ai peur que l'enfant soit malade : temo que el nino esté enfermo,
    • une appréciation,
    • une hypothèse.
  • Groupes de verbes :
    • Groupe Exemples de verbe Utilisation
    1er groupe : AR estudiar é, es, e, emos, eis, en (terminaisons du présent de l'indicatif des verbes du 2ème groupe sauf le "je" o -> é)
    2ème et 3ème groupes : ER et IR comer/escribir a, as , a, amos, ais, an (terminaisons du présent de l'indicatif des verbes du 1er groupe sauf le "je" o -> a)
  • Verbes irréguliers :
    • Les verbes irréguliers : saber (sepa, sepas, sepa, ...), ser (sea, seas, sea, ...), ir (vaya, vayas, vaya, ...), estar (esté, estés, esté, ...), ...
    Les verbes avec diptongo : garde la diptongo
    Les verbes irréguliers à la 1ère personne du singulier : hacer (haga), tener (tenga), pedir (pida), ...

Les temps du passé

  • Preterito perfecto (passé composé) / preterito indefinido (passé simple) / preterito imperfecto (imparfait)
    • Important !!! Quand utilise-t-on le Preterito perfecto (passé composé), quand le Preterito indefinido (passé simple) et quand l'imparfait (preterito imperfecto) ???
  • Utilisation des 3 temps ci-dessous :
    • Temps Utilisation
    Preterito perfecto (passé composé) On utilise le Preterito perfecto (passé composé) pour exprimer une action achevée dans le passé en lien avec le moment où l'on parle parce qu'elle se situe dans une unité de temps non révolue.
    Utilisation avec : Esta manana, ultimamente, ya/aun, este mes, ...
    Preterito indefinido (passé simple) On utilise le Preterito indefinido (passé simple) pour parler de faits ponctuels dans le passé dont l'unité de temps est révolue. Evénements passés avec des dates, ex: biographie.
    Utilisation avec: Ayer, el ano pasado, anoche, las vacaciones pasadas, aquel, ese mes, hace dos anos, ...
    Preterito imperfecto (imparfait) On utilise le Preterito imperfecto (imparfait) pour décrire des habitudes, des coutumes, des circonstances, des faits qui durent dans le passé ou une histoire dans le passé en mode narratif. L'imparfait présente des événements antérieurs au moment où l'on parle, sans référence à leur fin, au temps (dates) , action terminée ou non.
  • Remarque : concordance des temps
    • Action longue dans le passé (preterito imperfecto), interromptue par une action courte (preterito indefinido) - Concordance des temps

    Preterito perfecto (passé composé)

  • Construction :

    • Présent de haber + participio

    => haber (hé, has, ha, hemos, habeis, han)

    => participio : AR -> ado, ER/IR -> ido

    Preterito indefinido (passé simple)

  • Construction (3 groupes de verbes):
    • AR (ex: Hablar) Habl é/aste/o/amos/asteis/aron
    ER (ex: nacer) Nac i/iste/io/imos/isteis/ieron
    IR (ex: escribir) Escrib i/iste/io/imos/isteis/ieron
  • Verbes irréguliers :
    • estar : estuve, estuviste, estuvo, estuvimos, estuvisteis, estuvieron
    ir/ser : fui, fuieste, fue, fuimos, fuisteis, fueron

    Preterito imperfecto (imparfait)

  • Construction (3 groupes de verbes):
    • AR (ex: Estar) Est aba/abas/aba/abamos/abais/aban
    ER (ex: Tener) Ten ia/ias/ia/iamos/iais/ian
    IR (ex: Vivir) Viv ia/ias/ia/iamos/iais/ian
  • Verbes irréguliers :
    • ser : era, eras, era, eramos, erais, eran
    er : ir : iba, ibas, iba, ibamos, ibais, iban
    ir : ver : veia, veias, veia, veiamos, veiais, veian
  • Remarques :
    • estar à l'imparfait + gerundio (était en train de ) pour présenter une action passée en cours de déroulement
    Justement, on parlait de lui quand il est arrivé : Justamente estabamos hablando de el cuando llego

    Preterito pluscuamperfecto (plus que parfait)

  • Utilisation :
    • On utilise le preterito pluscuamperfecto pour parler de 2 actions dans le passé avec une antérieure à l'autre
    ex: Cuando llegamos (passé simple) al hotel, no habian cenado (preterito pluscuamperfecto)
  • Construction :

    • Preterito imperfecto de haber (habia/habias/habia/habiamos/habiais/habian) + participio (ado/ido)

Conditionnel

  • Utilisation / construction :
    • Cas d'utilisation Construction
    • exprimer une action future en relation avec le passé,
    • doute/probabilité dans un contexte passé,
    • atténuer une demande ou un conseil,
    • la politesse,
    • expression d'un souhait dans le présent.

Impératif

Attention !!! les pronoms personnels utilisés sont : tu, vosotros(as), usted(es)
  • Groupes / construction :
    • Groupes Construction
    Verbes du 1er groupe AR on retire le suffixe AR + a (pour le tu), ad (pour le vosotros/vosotras, e (pur le usted), en (pour le ustedes)
    Verbes du 2ème groupe ER on retire le suffixe ER + e (pour le tu), ed (pour le vosotros/vosotras, a (pur le usted), an (pour le ustedes)
    Verbes du 3ème groupe IR on retire le suffixe IR + e (pour le tu), id (pour le vosotros/vosotras, a (pur le usted), an (pour le ustedes)
  • Pour le "tu" c'est comme au présent mais sans le "s",
  • Verbes irréguliers : poner (pon), venir (ven), hacer (haz), decir (di), salir (sal), ser (sé), tener (ten), ir (ve).

    Verbes du 3ème groupe IR NO + on retire le suffixe IR + as (pour le tu), ais(pour le vosotros/vosotras, a (pur le usted), an (pour le ustedes)
